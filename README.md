# Протяжка фольги

Android-приложение для типографии: считает длину протяжки фольги при тиснении
горячим способом так, чтобы оттиски следующих ударов ложились в промежутки между
элементами клише — равномерно и с наименьшим риском наложения.

## Что вводится

Схема ленты фольги, как на эскизе: элементы (заштрихованные) и промежутки между
ними по направлению протяжки. Схема рисуется в масштабе введённых размеров и
перестраивается при вводе; от каждой размерной стрелки выноска ведёт к полю ввода в мм.
Клавиша «Готово» сворачивает клавиатуру, недопустимое значение выделяется красной рамкой.

- количество элементов — 2, 3 или 4;
- высота каждого элемента и промежутки между ними;
- минимальный зазор между соседними оттисками — запас на неточность протяжки
  и рваные края (по умолчанию 1 мм).

## Что выдаётся

- **оптимальная протяжка** — при ней зазоры между всеми соседними оттисками
  максимально выровнены, то есть риск наложения наименьший;
- **допустимый диапазон** — любая протяжка из него даёт то же вложение оттисков
  с зазором не меньше заданного; нижняя граница — самая экономная;
- зазор между оттисками и экономия фольги относительно протяжки на всю длину рисунка;
- схема: оттиски нескольких соседних ударов на фольге, пронумерованные по порядку;
- **расход фольги**: по тиражу (числу ударов) и намотке ролика — метры и ролики
  на тираж, на приладку (+20 % к расходу на тираж) и сколько целых роликов понадобится всего.

## Как считается

Рисунок одного удара — элементы `[sᵢ, eᵢ]` вдоль ленты, длина рисунка `L`.
После удара фольга сдвигается на `a`, поэтому удары `k` и `k + d` расходятся на `d·a`.
Элемент `i` позднего удара не должен подходить к элементу `j` раннего ближе зазора `δ`,
то есть для всех `d ≥ 1` и пар `i ≤ j`:

```
d·a ∉ (sⱼ − eᵢ − δ,  eⱼ − sᵢ + δ)
```

Недопустимые значения `a` — объединение интервалов `((sⱼ − eᵢ − δ)/d, (eⱼ − sᵢ + δ)/d)`.
Приложение перебирает их по возрастанию и находит первое окно допустимых протяжек
`[a_min, a_max]` — самое экономное вложение. Внутри окна каждый зазор между оттисками
линейно зависит от `a`, а наименьший из них — вогнутая функция; её максимум и есть
оптимальная протяжка. Если середины не хватает ни для одного оттиска, протяжка равна `L + δ`.

Для двух элементов `x`, `y` с промежутком `z` это совпадает с формулами:

```
n = ⌊(z − δ) / (x + y + 2δ)⌋        — сколько оттисков x и y ложится в середину
a_min = (x + y + z + δ) / (n + 1)    — самая экономная протяжка
c = (z − n·(x + y)) / (2n + 1)       — одинаковый зазор вокруг каждого оттиска
a = (x + y + z + c) / (n + 1)        — оптимальная протяжка
```

Пример: `x = 10`, `z = 60`, `y = 15` мм → `n = 2`, оптимальная протяжка 29,00 мм,
все зазоры по 2,00 мм; без вложения было бы 85 мм.

Расчёт — в [`FoilCalculator.kt`](app/src/main/java/io/github/ceniorpomidor/foildraw/calc/FoilCalculator.kt),
тесты сверяют его с прямым перебором ударов и с формулами для двух элементов.

## Установка

Готовый APK — в разделе **Releases** репозитория: файл `foil-draw-<версия>.apk`.
Для установки разрешите установку из неизвестных источников. Нужен Android 8.0 или новее.

Сборку из любого пуша можно взять во вкладке **Actions** → запуск **Android** →
артефакт `foil-draw-apk` (zip с APK внутри).

Там же артефакт `screenshots` — снимки экрана для 2, 3 и 4 элементов и тёмной темы,
которые рисует UI-тест на Robolectric.

## Сборка

```
./gradlew testDebugUnitTest   # тесты расчёта
./gradlew assembleRelease     # APK в app/build/outputs/apk/release/
```

Нужны JDK 21 и Android SDK (compileSdk 36). APK подписывается ключом
`app/foildraw.keystore` из репозитория, чтобы новая сборка ставилась поверх
старой без удаления. Ключ открытый, поэтому для публикации в магазинах
приложений он не годится.

## Выпуск версии

1. Поднять `versionCode` и `versionName` в `app/build.gradle.kts` и описать изменения
   в разделе этой версии в [`CHANGELOG.md`](CHANGELOG.md).
2. Запустить workflow **Android** вручную (Actions → Android → Run workflow) с отметкой
   `release` — или отправить тег `v<версия>`.
3. GitHub Actions соберёт APK и опубликует релиз `v<версия>` с текстом из `CHANGELOG.md`.
